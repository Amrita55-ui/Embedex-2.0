The Silent Leak 🚨

About the Project
The Silent Leak is an IoT-based gas leakage detection system designed to detect gas leaks and help prevent accidents.

Objectives
Detect gas leakage using a gas sensor.
Use an ESP8266 microcontroller to process sensor readings.
Activate an alert when gas is detected.
Use a servo motor to operate the gas regulator mechanism.
Send sensor readings to ThingSpeak for online monitoring.

Components Used
ESP8266
Gas sensor
Servo motor
Jumper wires
Power supply
ThingSpeak IoT platform

Team Name
RoboFlux

Project Category
Internet of Things (IoT)

Future Scope
A website dashboard for monitoring sensor readings and viewing the system status.
