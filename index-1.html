Set up this Netlify page

In the SETTINGS section below, enter your ThingSpeak Channel ID and read API key. The channel must allow public reads. Keep the channel write key only in the ESP sketch. Redeploy this folder to Netlify after changing the page.

Prototype display only. Browser alerts work only while this page is open and notifications are allowed. Keep certified gas and smoke alarms installed. Do not use this prototype to operate a gas valve.
